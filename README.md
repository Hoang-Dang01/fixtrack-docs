# FixTrack Documentation

Repository tài liệu độc lập của FixTrack, gồm đặc tả hệ thống, quy tắc nghiệp vụ, API handoff và báo cáo triển khai backend.

Điểm bắt đầu:

- `SSS_V2_BACKEND_CANONICAL.md`: đặc tả backend chuẩn hiện hành.
- `BACKEND_API_HANDOFF.md`: hợp đồng bàn giao API cho frontend.
- `SSS/MASTER_INDEX.md`: mục lục bộ đặc tả đầy đủ.
